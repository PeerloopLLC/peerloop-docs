# Conv Decisions - 2026-09-04

## 1. Reviews tab as a contextual (active-only) tab
**Type:** Implementation
**Topics:** astro

**Trigger:** Client wanted Reviews out of the tab bar but the `/reviews` route still reachable (via the banner rating chip); removing it outright left `/reviews` with no "you are here" anchor — bad UI.

**Options Considered:**
1. Fully remove the tab (disorienting — no location anchor)
2. Contextual tab — appears + highlighted only when on `/reviews` ← Chosen
3. In-content header only
4. Revert

**Decision:** Add an `activeTab` param to `buildCourseExploreTabs`; append a highlighted Reviews tab only when `activeTab === 'reviews'`. `[...tab].astro:153` passes `tab`.

**Rationale:** Satisfies "no Reviews tab in the browse strip" while restoring the location anchor when the route is active.

**Consequences:** `activeTab` param added to `buildCourseExploreTabs`; only `[...tab].astro` passes it. New reusable "contextual tab" pattern.

## 3. Merge Teachers into Members as a composite; /teachers 301→/members
**Type:** Implementation
**Topics:** astro

**Trigger:** Client asked to merge the overlapping Teachers/Members tabs (they duplicate teachers + creator; students appear only in Members).

**Decision:** Members tab renders a Teachers section (creator first + peer teachers, rich `TeacherCard`) atop a Students section, with one search; the standalone Teachers tab is removed, `/teachers` 301s to `/members`, and the orphaned `TeachersTab.astro` is deleted. Creator without teaching stats renders `hideStats`; a "Meet the Creator" link points to `/course/[slug]/creator`.

**Rationale:** Single directory, no duplicate creator/teacher rows; link-honesty preserved via a 301 redirect.

**Consequences:** `TeacherCard` exported from `TeachersTabList` + extended (hideStats, creatorPageHref, handle, role pill, "Visit Member"). Breaking route change: `/teachers` no longer serves its own tab.

## 4. Uniform button styling: white/outlined + pastel-blue hover, message glyph + "Message", 12px icon
**Type:** Implementation
**Topics:** astro

**Trigger:** Client flagged inconsistent background/hover/messaging across member rows plus taller Message buttons.

**Decision:** All row buttons `variant="outlined"` (white) with `transition-colors hover:bg-primary-light`; message glyph + "Message" everywhere; Message + Visit Member grouped at row end (`sm:ml-auto`); Meet-the-Creator outlined (option B); whole-row hover/click removed on student rows; message icon passed as a 12px node to equalize height.

**Rationale:** One coherent, consistent affordance across teachers and students.

**Consequences:** `TeachersTabList` + `CourseMembersTab` restyled; button heights unified.

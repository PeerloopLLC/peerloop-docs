# Conv Decisions - 2026-09-25

## 1. Announce on effective-live transitions, toggle defaults ON at create, publish force-enables (A″)
**Type:** Implementation
**Topics:** stream, courses, feeds

**Trigger:** Client wanted the toggle ON by default + a dated "feed began" post; the draft→publish lifecycle made "began" ambiguous.

**Options Considered:**
1. Provision at course creation (first cut — wrong: dates the post at draft-creation, invisible until publish)
2. B — toggle turns ON only at publish (toggle reads OFF during draft)
3. A′ — toggle ON at create; publish makes it live; publish respects a draft-time OFF
4. A″ ← Chosen — toggle ON at create; **publish always forces the toggle ON** and provisions/announces

**Decision:** Toggle defaults ON at creation (INSERT flag, no Stream call). Feed live = published AND enabled. Announcements fire on effective-live transitions, each dated `formatDateTimeUTC(now) + " UTC"`: publish → "started"/"started again" (force enabled=1 + provision); unpublish → "turned off"; manual toggle on(published) → "started again"/off → "turned off"/draft → silent.

**Rationale:** Separates intent (toggle) from live state (is_active); satisfies "default ON" *and* "publish turns the feed on"; keeps announcements out of invisible draft feeds.

**Consequences:** New shared helper `src/lib/course-discussion-feed.ts` (activate/deactivate). Stream failures non-fatal everywhere; a failed first-provision rolls the toggle back to OFF so the public feed can't 500. Schema default stays `0` (safety net for seeds/tests). Applied to the creator self-serve flow only (matches `[CRTEACH]` scope); admin bare-create endpoint unchanged.

## 2. CI-safe render E2E via mocked feed; real-Stream round-trip deferred
**Type:** Implementation
**Topics:** testing, e2e, stream

**Trigger:** "How to test the feeds."

**Options Considered:**
1. Manual walk on local dev
2. Automated browser walk / PLATO
3. A ← Chosen — CI-safe Playwright render E2E (mocked feed) + optional real-Stream companion

**Decision:** New `e2e/course-discussion-feed.spec.ts` following the `course-feed.spec.ts` + `mockFeedApi` pattern, asserting `MattCourseFeed` renders the system announcements. Real-Stream round-trip parked as `[DISC-E2E-REAL]`.

**Rationale:** PLATO and unit tests mock Stream (can't assert feed content); real-Stream E2E can't run in CI (no creds). The render is the genuinely-uncovered, CI-testable gap.

**Consequences:** 2 E2E tests, run green live. Publish re-activation, publish Stream-failure rollback, and disable-when-not-live left untested by user decision.

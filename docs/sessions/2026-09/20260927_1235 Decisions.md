## 1. Brian-era styling is left unattributed
**Type:** Strategic
**Topics:** provenance, cc-workflow

**Trigger:** User noted Brian has taken over the final style; the Matt-era 3-marker convention no longer cleanly describes new/changed pages.

**Options Considered:**
1. Leave convention as-is, no note
2. Add a forward note; keep the 3 markers unchanged ← Chosen
3. Introduce a new `@brian-*` marker axis now

**Decision:** Keep the 3 markers; add a note (CLAUDE.md §Page Provenance + matt-provenance.md §11) that markers capture Matt-era heritage only, Brian's changes carry no marker (new pages unmarked; restyled attributed pages keep their existing marker, not re-attributed), and no `@brian-*` axis exists by design.

**Rationale:** Brian's contribution to already-attributed pages isn't cleanly separable from the Matt baseline; new work is unmarked; 0 distinct Brian pages exist so a new marker axis is premature. A future full-restyle scan may reconstruct a fresh style guide.

**Consequences:** Existing `@matt-*` markers now read as "originated Matt-era," not "current styling"; consult git diffs for Brian's subsequent changes.

# Conv Learnings - 2026-09-25

## 1. The discussion feed's "live" state is two flags, not one
**Topics:** stream, courses, feeds

**Context:** The client asked to default the toggle ON and post "feed began"; the first cut wrongly tied it to course creation.

**Learning:** A course feed is visible/postable only when `is_active = 1 AND discussion_feed_enabled = 1`. The public GET (`/api/feeds/course/[slug]`) filters `is_active = 1`, so a draft's feed is invisible regardless of the toggle. Announcements must therefore key off the **effective-live** transition (published AND enabled), not off either flag alone — otherwise you post into an invisible draft feed with a stale date.

**Pattern:** For any "announce when X turns on" feature, define the observable state precisely (here: the AND of two columns) and drive side-effects off transitions of *that*, computed before/after each mutating action.

## 2. Layered test coverage: mocks for logic, E2E-with-mocked-network for render, real-service only where it's the actual risk
**Topics:** testing, e2e, stream

**Context:** "How to test the feeds" — the unit tests mock Stream.

**Learning:** Unit/integration tests (mocked Stream) prove *which* announcement fires per transition + the flag states. The uncovered gap was the **render** of a `system: true` activity in `MattCourseFeed` — coverable in CI via the existing `mockFeedApi` Playwright pattern (no Stream creds). The real Stream network hop is the only thing left, and it needs real creds → local-only/opt-in, not CI. Match the test layer to the specific risk rather than reaching for a full real-service E2E.

## 3. `astro dev` daemonizes; a 500 with a clean build is the stale-Vite-cache brick
**Topics:** cloudflare, astro, testing

**Context:** The dev server on :4321 returned 500 during E2E setup.

**Learning:** Per `[DEVSRV-STALE]`: `npm run dev` (astro 7) daemonizes (survives the foreground command's exit), and a 500 on a route while `npm run build` is clean = stale `node_modules/.vite` dep-optimizer cache. Fix: `npx astro dev stop` → `rm -rf node_modules/.vite` → restart. Never port-kill (`lsof -ti` returns Chrome).

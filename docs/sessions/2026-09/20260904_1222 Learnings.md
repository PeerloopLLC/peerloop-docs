# Conv Learnings - 2026-09-04

## 1. String icon in a shared button forces size-icon-20; pass a node to size it
**Topics:** astro, testing

**Context:** Message buttons rendered ~8px taller than text-only buttons on the Members-tab rows.

**Learning:** `MessageUserButton` renders a *string* `icon` prop at `size-icon-20`; `text-body-small` has `line-height:1` (12px), so a 20px icon inflates the row height. Passing the icon as a ReactNode (`<MattIcon name="message" className="size-icon-12" />`) is the documented escape hatch and matches the text line box, equalizing heights.

**Pattern:** For equal-height icon+text vs text-only buttons where line-height is 1, size the icon to the font-size (12px node), don't rely on the component's default string-icon sizing.

## 2. The icon codecheck gate only validates literal `<MattIcon name="...">`, not runtime-var names
**Topics:** testing, cc-workflow

**Context:** `icon="mail"` (a string prop into a shared component) passed codecheck but rendered a broken/empty 20px box for several turns; the literal `<MattIcon name="mail">` would have failed the ICON gate.

**Learning:** A runtime-variable icon name (`<MattIcon name={icon}>` inside a shared component) is invisible to the static ICON gate — an invalid name slips through and renders empty while the button still "works" (label + click). Using a literal node surfaces the validation. There is no envelope/`mail` glyph in `svg/*` (only `chat`, `message`); use `message`.

## 3. `git log -S` on the current branch misses features authored on a parallel branch
**Topics:** cc-workflow, dual-repo

**Context:** "Members tab is hidden" — a `git log -S` on `jfg-dev-14` found nothing, so the feature looked deleted.

**Learning:** A feature can be fully absent (never merged) rather than removed. Use `git log --all -S`, `git merge-base`, and `git merge-base --is-ancestor` to distinguish "removed from our line" from "authored on a fork, never merged." Here the branches forked at `c50afd82` (Jul 7, Conv 370); the Members commit `51e1f1e3` (Jul 21) lives only on `brian-July-20` and was never an ancestor of our branch.

# Conv Decisions - 2026-09-04

## 1. Homework merged into Sessions as a hybrid (Option C), route redirected like Teachers
**Type:** Implementation
**Topics:** course, astro, react

**Trigger:** Client asked to fold the standalone Homework tab into the Sessions tab; homework is session-scoped.

**Options Considered:**
1. Interleaved-full — full submit UI inline under each session
2. Separate section — relocate HomeworkTab as a section, un-tied to sessions
3. Hybrid — per-session inline indicator + full submit UI below/on-expand ← Chosen

**Decision:** Option C. SSR loader supplies per-module + course-level homework summaries for inline indicators; the existing `HomeworkTab` island is reused wholesale below the module list. `/homework` 301→`/modules` and the strip entry is removed, mirroring the Conv-445 Teachers→Members merge.

**Rationale:** Reuses the heavy submit/feedback island unchanged (low risk), keeps homework tied visually to its session, and the redirect keeps deep links (reminder emails) resolving.

**Consequences:** New `CourseHomeworkSummary` type + `homework`/`courseHomework` fields on the modules view; `HomeworkTab` gained an optional `moduleSessionMap` prop; the enrolled-only Homework strip tab is gone. Known tradeoff: the badge indicator (SSR snapshot) and HomeworkTab (client fetch) double-source the same data — acceptable for a status snapshot.

## 2. Number sessions by position; leave the session_number column as-is
**Type:** Implementation
**Topics:** course, d1

**Trigger:** `1,1,2` numbering; ambiguity whether `session_number` is bad data or an intentional multi-module grouping.

**Options Considered:**
1. Fix the seed data (mock-data.ts) + reseed
2. Number by position in the display, leave the column ← Chosen
3. Treat the grouping as intentional (no fix)

**Decision:** User confirmed Session↔Module is 1:1 → number by curriculum position in `ModulesTab`; do not migrate the `session_number` column (it stays creator-editable in the studio).

**Rationale:** The display fix corrects all affected courses at once, needs no migration, and doesn't disturb the creator-owned column or the `CurriculumEditor` badge.

**Consequences:** Student-facing Sessions tab now numbers sequentially regardless of stored `session_number`.

## Prompts & Actions

### Community medallion straddle (card cover ↔ blue band)
**User:** wanted the community logo to overlap both the course image and the blue affiliation band.
**Claude:** Measured — the seal (`CommunityAffiliation` band) sat 2.9px *inside* the band (bottom-anchored `bottom-[6px]`), 0px overlap. Re-anchored to the band's top edge; then a follow-up (15% bigger, 20px from card left, shallower band, text closer) exposed the real root cause: the seal was **never truly absolute** on the monogram branch — `CommunityAvatar`'s base `relative` class beats an appended `absolute` (Tailwind orders `.relative` after `.absolute`), so the 40px seal stayed *in* the flex flow and propped the band open to 56.9px. Fixed by wrapping the seal in an absolute `<span>` (out of flow → band collapses to ~28px), sized 46px (`CommunityAvatar` gained a `size-46`), centred on the band's top edge (`-top-[23px]`).

### Meta line baseline misalignment (creator / rating / state)
**User:** the 3rd portion of the creator/rating line sits ~3px below the first two.
**Claude:** First tried `leading-[20px]` and wrongly reported it "verified −0.9px" — I had compared line-box *tops* of a 12px box vs a 20px box, not glyph ink. User pushed back ("Not visually fixed"). Re-measured glyph baselines via `Range.getBoundingClientRect()`: still 3.2px low. Real cause: the creator/rating chips are wrapped in inline `<a>` links; an inline anchor around an inline-flex chip gets a ~26px line box (leading), floating its text ~3px above row centre. Fix: `inline-flex items-center` on the link wrappers → collapse to the chip's 20px height → baselineDelta 0.00.

### Relocate the price pill off the cover into the title row
**User:** move the price to the right side of the card; make room via an always-2-line title (limit width) + a constrained CTA. [Chose **A**: price pinned top-right, CTA beneath, right-aligned stack.]
**Claude:** `CourseCoverPanel` gained `showPriceSticker` (default true; /courses passes false); `CoursePriceSticker` gained an `inline` (in-flow) variant. Title row restructured: title left (`line-clamp` + `min-h-[Nlh]` + fixed width), 156px right zone with inline price over a `Small` CTA. Verified price lands 21px from the card edge on every card. Detail hero + community cards keep their cover sticker (they use the sticker directly / default true).

### Tooltips, 3-line title, responsiveness
**User:** tooltip for title + write-up when truncated; allow 3 lines for the title; fix mobile (CTA + title compromised).
**Claude:** Added `useEllipsisTooltip` hook (ResizeObserver, `scrollHeight > clientHeight`) → native `title` only when actually truncated; description wrapped in its own card link so it's hoverable *and* clickable under the stretched-link overlay. Title clamp made responsive: `line-clamp-2 min-h-[2lh]` mobile, `@xl:line-clamp-3 @xl:min-h-[3lh]` desktop (the `lh` CSS unit resolves to 2×/3× line-height). Restored the `@xl` reflow dropped by the fixed-width build: mobile stacks a fluid full-width title + top-right price + full-width CTA; @xl is the two-column layout.

### Title width tuning + yellow debug bg
**User:** narrower title; add a light-yellow bg to see edges; try 180 → "180 is perfect", "leave the yellow" for client to decide.
**Claude:** Fixed title box width (experimental yellow `bg-[#fef9c3]`), tuned 160 → 180px at desktop. Yellow bg intentionally left ON pending client review (committed as-is).

### Meta-line mobile indent (medallion overlap)
**User:** give the creator/rating line a left margin (~100px) at mobile only so the community logo doesn't overlay it.
**Claude:** Confirmed mobile-only cause: at @xl the cover is a left panel so the meta line lives in the right column (clear of the bottom-left seal); at <@xl the cover is a top banner and the meta line goes full-width from 20px, under the seal. Added `pl-[100px] @xl:pl-0`, gated on `community` present. (Noted ~76px would align with the band's own text.)

### Badge audit + move Enrolled/Completed
**User:** which pills over the image? New/Popular/Featured stay; Bestseller + Admin stay; move Enrolled/Completed to the meta line (B) as a pill with a check for completed.
**Claude:** Enumerated: marketing badge (Featured/Popular/New/Bestseller, top-left), enrollment (Enrolled/Completed, was stacked top-left), admin attention count (top-right, admin-only). Removed the enrollment span from the cover; added a meta-line pill (course-colour, rounded-full, `✓ Completed` / `Enrolled`).

### Right-justify the state, simplify completed
**User:** right-justify the 3rd component (state) against the card's right border on non-mobile; when completed drop "3 of 3 sessions" and (verified) "Diploma earned".
**Claude:** Grouped pill+progress into one `flex items-center gap-8` div with `@xl:ml-auto` so the state block right-justifies as a unit (21px from card edge). Verified diploma is awarded *at* completion (DiplomaEmail / PrecheckoutContent / `diploma_awarded_at`) — coincident with completed, no extra state → removed both for completed cards; completed shows only the `✓ Completed` pill.

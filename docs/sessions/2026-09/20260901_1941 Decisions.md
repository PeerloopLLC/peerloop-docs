# Conv Decisions - 2026-09-01

## 1. Price relocated to the title row via a per-surface opt-out, not a shared removal
**Type:** Implementation
**Topics:** astro

**Trigger:** Client wants the price off the /courses cover; but the price sticker lives in the shared `CourseCoverPanel` (also used by `CommunityCatalogCard`) and `CoursePriceSticker` is used directly by the detail hero.

**Options Considered:**
1. Remove the sticker from `CourseCoverPanel` outright
2. Add a `showPriceSticker` prop (default true); only /courses passes false ← Chosen
3. Fork a /courses-specific cover panel

**Decision:** Prop-gated opt-out + an `inline` variant on `CoursePriceSticker` for the in-row placement.

**Rationale:** Keeps the detail hero and community cards unchanged; one component, no drift.

**Consequences:** `CourseCoverPanel` gained `showPriceSticker`; `CoursePriceSticker` gained `inline`.

## 2. Enrollment state moved off the cover into the meta line as a pill (option B)
**Type:** Implementation
**Topics:** astro

**Trigger:** Client: New/Popular/Featured/Bestseller + admin badge stay on the cover; Enrolled/Completed must move.

**Options Considered:**
1. Status chip after the title
2. Into the meta line beside the progress it describes ← Chosen
3. In the right stack above price/CTA

**Decision:** Meta-line pill (course-colour, rounded-full), `✓ Completed` with a check / `Enrolled` without; grouped with progress and right-justified on non-mobile.

**Rationale:** Groups the journey info; keeps the cover to marketing badges only.

**Consequences:** Cover badge slot simplified to the marketing badge; state block right-justifies via `@xl:ml-auto`.

---

## 3. "Diploma earned" removed as redundant with "Completed"
**Type:** Implementation
**Topics:** astro

**Trigger:** Client asked to drop "3 of 3 sessions" for completed courses, and "Diploma earned" *unless* it means more than completion.

**Options Considered:**
1. Keep "Diploma earned" as a distinct achievement line
2. Remove it — verified coincident with completion ← Chosen

**Decision:** Completed cards show only the `✓ Completed` pill (no session count, no diploma text).

**Rationale:** Verified via `DiplomaEmail` / `PrecheckoutContent` / `diploma_awarded_at` that the diploma is awarded *at* completion — a real credential (`/diploma/{id}`) but no state beyond completed, and this card has no diploma link.

**Consequences:** Flagged a future option: a "View Diploma" link (→ `/diploma/{id}`) if the credential should be surfaced here.

# Conv Learnings - 2026-09-27

## 1. Probe the live source before declaring a convention stale
**Topics:** cc-workflow, provenance

**Context:** The plan flagged the Page Provenance 3-marker convention as a likely stale-cleanup target after Brian took over styling.

**Learning:** A grep of `src` showed 180 active markers (@matt-inspired 107, @matt-source 58, @stand-in 15) and 0 `@brian` markers — the convention is thriving, not dying. The correct action was to *record a forward governance note*, not prune. Investigating before editing (the "probe the authoritative source before inferring" guard) flipped the whole pass from deletion to documentation.

## 2. A wholesale system-retirement sweep leaves semantic stragglers
**Topics:** cc-workflow, docs-infra

**Context:** The Conv 456 memory-retirement sweep repointed `memory/` path citations mechanically.

**Learning:** Two live references survived because they were *semantic*, not path-shaped: a task's `Refs:` line naming a since-deleted doc, and an `r-quiet-mode` step describing a "memory-save candidates / check the memory dir" discipline that no longer exists. A post-deletion `grep` for the bare filenames (not just path-prefixed forms) surfaced them.

**Pattern:** After a system-retirement sweep, grep bare file basenames (not only the old path-prefixed link forms) across live files to catch semantic stragglers.

# Conv Decisions - 2026-07-25

## 1. Enrollment-stepper link affordance = persistent underline
**Type:** Implementation
**Topics:** ui-ux, astro

**Trigger:** Users can't tell which stepper steps are clickable (identical-green Enroll-static vs Payment-link).

**Options Considered:**
1. Persistent underline at rest ← Chosen
2. Trailing chevron `›`
3. Hover-only pill+underline

**Decision:** Underline the *label* of linked steps at rest (`decoration-1`, hover→`decoration-2`), both orientations, decoration inherits the label's own colour.

**Rationale:** Only a resting cue answers "which can I click?" at a glance and on touch; hover-only fails. Underline is the codebase's link vocabulary and good a11y (not colour-alone). No new token → prov clean.

**Consequences:** `CourseJourneyStepper.astro` shared `linkUnderline` const on the two linked-label sites.

## 2. Modules-tab hover = neutral tint (resolve the pale-green ↔ course-CTA collision)
**Type:** Implementation
**Topics:** ui-ux, matt-design-system

**Trigger:** The green hover tint (`bg-course-background`) is identical to the `variant="course"` Button base fill (page-wide), so hovering a ghost element looks like a resting CTA.

**Options Considered:**
1. Neutral grey hover (`bg-neutral-50`) ← Chosen
2. Solid dark-green CTA (restyle the course button page-wide)
3. Stronger-green hover tint

**Decision:** Change the 4 Modules-tab hovers to the dominant `hover:bg-neutral-50`; leave the course buttons.

**Rationale:** No light green can separate from the pale-green button (both light-green-on-white); a neutral tint reads unambiguously as feedback, never a CTA, and doesn't fight the course tone. Localized to what was just edited; buttons page-wide untouched.

**Consequences:** Also fixed the prior blue-on-green clash. Course-variant button base is confirmed = the hover-green — informs future hover choices.

## 3. Sticky course CTA hover = subtle darker-green tint, variant-aware
**Type:** Implementation
**Topics:** ui-ux, matt-design-system

**Trigger:** The pale `variant="course"` sticky CTA had no perceptible hover (opacity-dim invisible on pale-on-white).

**Options Considered:**
1. Solid-fill hover, sticky CTA only
2. Solid-fill hover, all course buttons page-wide
3. Subtle darker-green tint ← Chosen

**Decision:** `SubNav.astro` `actionHover` = variant-aware; `course` → `transition-colors hover:bg-course-primary/20 hover:border-course-primary/20` (deeper pale green, dark text kept); other variants keep `hover:opacity-90`.

**Rationale:** User wanted a subtle colour change (not a bold solid flip); `course-primary/20` is an existing token via opacity modifier (prov-clean, no new colour). Variant-aware so blue primary/community CTAs aren't recoloured green.

**Consequences:** Applies to every sticky SubNav action (course + community). DOM-verified rest #E8F4DF → hover ≈ #D6E5CC.

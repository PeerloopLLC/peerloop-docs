### Per-element call-site attribution

**User:** "What do you recommend we do next? we have used 240K tokens and are good to go to 400K if it means the progress can be improved with the current conv's context"

**Claude:** Recommended per-element attribution as the highest-value use of loaded context — the block's claim ("every rendered token scaled") was weaker than it sounded because nothing mapped a rendered icon back to its source site. **User:** ▸ chose "Per-element attribution (Recommended)"

**Claude:** **The spike killed the proposed approach.** A build-time `data-icon-src` stamp cannot work: `MattIcon` and every `ui/icons.tsx` component have **closed prop interfaces** (`{name, className}` / `{className}`, no `...rest`), so an injected attribute is silently dropped; making it work meant editing shared production primitives for a dev-only measurement.

Used React 19's `_debugStack` instead — `_debugSource` **was** removed in React 19 (verified empirically via a live fiber probe, not taken from memory). Walking up while `className` is the same string lands on the element written at the call site. **95% attribute** (252 of 265 over 6 routes), with no babel plugin, no Vite transform, and no production change.

Built into the scanner: served-URL → repo-path normalisation (Vite alias ids + real paths), a static `size-icon-*` inventory per file, and a completeness ledger comparing the two. `--ledger` forces the report on a partial run (suppressed by default there, since a subset understates coverage).

**Claude (instrument bug caught):** The ledger's first output labelled **625 of 690** sites "component defaults", including 27 in `Sidebar.tsx` — a consumer. The regex used `className\s*=\s*`, and `\s*` matches zero spaces, so it swallowed JSX attributes along with genuine destructuring defaults. The comment stated the rule correctly; the regex did not implement it. `\s+` fixes it — true split **107 defaults / 522 call sites / 61 `.astro` = 690**. (A first write-up of this said "457 JSX attributes"; that was a raw `className="` grep which missed template literals and did not partition the total. Corrected at r-end by the update-plan agent re-running the ledger's own classifier — an instrument-verification miss inside the write-up *about* instrument verification.)

**Claude (final ledger):** 629 attributable static sites across 176 files, **238 proven rendered (38%)**, +61 `.astro` sites named as a blind spot (SSR, no React fiber). Verified the largest unproven block was a real finding rather than a blind spot: `ui/icons.tsx` exports 98 icon components each defaulting to `size-icon-20`, but only **6 usages app-wide omit `className`** (4 in the parked page) against **381** that pass one — the defaults are near-dead by construction. Orphan detector returns **PASS**, so the residue is state-coverage, not dead code. Committed code `15711c00`, docs `09aeea5`.

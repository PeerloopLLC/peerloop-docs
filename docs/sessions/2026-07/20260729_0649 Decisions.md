**Type:** Implementation
**Topics:** tooling, dev-server

**Trigger:** The task specified "capture the spawned PID, kill only that on teardown".

**Options Considered:**

2. Use astro's native `astro dev stop`, which reads `.astro/dev.json` ← **Chosen**

**Decision:** Close it natively — no new script.

**Rationale:** astro 7 prints the spawned pid and writes a lock; `stop` kills exactly that pid. Proven against the literal Conv-393 failure (fallback to :4322, `stop` took ours, spared the squatter and Chrome). A wrapper would duplicate first-class tooling.

**Consequences:** No new script to maintain; teardown guidance is now one command, propagated to memory and docs.

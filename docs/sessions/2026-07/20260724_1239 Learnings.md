# Conv Learnings - 2026-07-24

## 1. Reuse the positional module↔session source-of-truth; don't re-derive it
**Topics:** ssr, booking, course-tabs

**Context:** The curriculum-first Modules tab needs each module to know *its* session state. The DB `sessions.module_id` is NULL until completion (frozen on complete), so a naive "join sessions on module_id" loses every booked-but-not-completed session.

**Learning:** `@lib/booking`'s `resolveModuleAssignments(db, enrollmentId)` is the app's positional SoT — it maps every active session (completed→frozen module_id; scheduled/in-progress→positionally to the remaining modules) to a module. The clean loader is: reuse it for module↔session_id, then enrich each session_id from `fetchStudentCourseSessions` (which carries teacher/times/recording) by joining on id. Cancelled/no-show are excluded from the assignment (they don't advance the curriculum) → pull them from `fetchStudentCourseSessions` for a history tail.

**Pattern:**
```ts
new Map(assignments.sessions.map(a => [a.module_id, a]))
+ new Map(allSessions.map(s => [s.id, s]))
// then: curriculum.map(m => enrich(assignByModuleId.get(m.id)?.session_id))
```

## 2. Provenance reclassification churns prov:sweep — keep the source stamp, document the drift
**Topics:** provenance, matt-provenance

**Context:** The merged ModulesTab is no longer a 1:1 Figma mirror (it now carries the session overlay). Instinct was to reclassify `@matt-source`→`@matt-inspired`.

**Learning:** This block's own M1 build (Conv 409) already tried that reclassify and it *added 2 prov:sweep errors* (reverted). The durable, baseline-neutral move for a big drift: keep the `@matt-source <node>` stamp (the curriculum spine IS still Matt's frame) and document the additive change as a Strict-B drift in the header — same call as M1/M12. When *absorbing* a separate registered `@matt-inspired` component (MySessionsTab), delete both the file and its `matt-inspired-registry.ts` entry → net-zero prov:sweep offenders.

## 4. Promoting a surface into the tab strip makes its old sub-row nav redundant
**Topics:** course-tabs, nav

**Context:** The `CourseSessionsActions` sub-row (on /book + /session/[id]) led with a "My Sessions → /sessions" entry.

**Learning:** Once "My Sessions" became the top-strip Modules tab, that sub-row entry duplicated the strip tab on every page that shows both. Dropped it, keeping only the two genuine actions ([Book a Session][Prepare/Join]). Reconciliation, not addition — matches the disposition's "actions live inside session rows" note.

4. **Discovered Matt formalized icon sizes** — his Figma "Icon Size" collection is Small 20 / Medium 24, and `05-color-and-tokens.md` proposed `--Icon-Size-Medium/Small` which was never implemented. Credited both as `✓ Matt`, marked the other nine CC-owned.

Built `--icon-{12..64}` (rem) + `--icon-inline-{sm,md,lg}` (em). First probe was **invalid** — injected classes at runtime, but Tailwind generates by scanning source.

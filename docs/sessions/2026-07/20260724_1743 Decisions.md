# Conv Decisions - 2026-07-24

## 1. Collapse the CourseHeader variant system (vs unify size only)
**Type:** Implementation
**Topics:** navigation, matt

**Trigger:** User asked "why are there different variants at all?" after the hero was found too tall.

**Options Considered:**
1. Unify the size, keep the `variant` prop machinery
2. Collapse the variants entirely — derive state from data ← Chosen

**Decision:** Removed `variant`/`headerHref` + the dead `enrolled` branch; the hero derives its state from `isEnrolled` (pill) and `scheduledSession` (session column vs includes+CTA).

**Rationale:** The `enrolled` variant was dead code and the height divergence was an accidental M1 leftover; collapsing dissolves the premise rather than papering over it.

**Consequences:** Simpler component + 3 call sites lost the `variant` prop; one slim state-derived band; stale doc fixed.

## 2. Container-query reflow (vs raise the viewport breakpoint)
**Type:** Implementation
**Topics:** navigation, layout, astro

**Trigger:** Right content clipped at mid widths (sidebar-collide) — `sm:flex-row` keyed off viewport, not the content column.

**Options Considered:**
1. Container query (`@container`, reflow on the hero's own width) — durable but novel to this codebase ← Chosen
2. Raise the breakpoint to `xl:flex-row` — simple, established, but stacks taller on laptops
3. Raise to `lg` — risks a residual clip at the sidebar transition

**Decision:** Introduced the first `@container` usage in the codebase; the hero reflows on its own width.

**Rationale:** Only a container query reflows correctly through the sidebar-collide zone (viewport breakpoints can't know the sidebar ate width). Confirmed Tailwind v4.3.3 has it as core.

**Consequences:** New pattern (`@container` + `@lg:`); later refined by decision 3.

## 3. Shrink-to-wrap the right column to stay compact (vs literal 2-line label / revert reflow)
**Type:** Implementation
**Topics:** navigation, layout

**Trigger:** The container-query fix stacked the n8n hero to a "very deep" 332px in a mid-width band.

**Options Considered:**
1. Shrink + wrap: right column shrinks so the label wraps, hero stays side-by-side ~198px, stack only true mobile ← Chosen
2. Literal 2-line label only (keep stacking) — doesn't fix the depth (stays 332px stacked)
3. Revert the reflow entirely — the original narrow-width clipping returns

**Decision:** Removed `shrink-0` from both right columns; `@3xl`→`@lg` reflow; left cluster `min-w-0`; scheduled col `text-right`.

**Rationale:** Keeps the hero compact at every tablet/desktop width AND wraps the label (the user's instinct) — Playwright-verified uniform 198px, no clip, no jank.

**Consequences:** Hero holds side-by-side to 512px, wraps the session label when tight, stacks only at true mobile.

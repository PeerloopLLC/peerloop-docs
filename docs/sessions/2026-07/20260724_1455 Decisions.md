**Topics:** navigation, migration

**Options Considered:**
1. Remove/301 the tab immediately
2. Fix the 2 parity gaps, THEN retire (301 → /modules) ← Chosen

4. Ship M3 as-is, leave the empty tab

**Consequences:** `/course/[slug]/modules` is now the single files surface; `/resources` is a permanent redirect; 6 public explore tabs (was 7).

# Conv Decisions - 2026-08-18

## 1. Blank Panel Placeholder
**Type:** Implementation
**Topics:** course-page, community-page, client

**Trigger:** Client requested full-height right panel on course and community detail pages.

**Options Considered:**
1. Keep existing DiscoveryRailPanel content ← Not chosen (client wants blank for now)
2. Remove the panel entirely ← Not chosen (structure needed for future)
3. Blank placeholder with bg-primary-light ← Chosen

**Decision:** Right panel on course and community detail pages is a blank `bg-primary-light` placeholder — content TBD by client.

**Consequences:** Both pages have the full-height panel structure; content to be specified later.

## 2. Meet the Creator Visual Distinction
**Type:** Implementation
**Topics:** course-page, client

**Trigger:** Client wanted Meet the Creator section visually separated from About tab content.

**Options Considered:**
1. Same styling as About (no distinction) ← Not chosen
2. Divider only ← Not chosen (user wanted more)
3. Background color only ← Not chosen
4. Both: thick divider + background color ← Chosen

**Decision:** 4px rounded divider + `bg-primary-light rounded-lg p-16` wrapper for the section.

**Consequences:** Clearly delineates the two conceptually different sections within the About tab.

---

## 3. Auth-Based Tab Ordering
**Type:** Implementation
**Topics:** course-page, ux, client

**Trigger:** Client specified different tab orders for visitors vs signed-in users.

**Options Considered:**
1. Same order for everyone ← Not chosen (client requirement)
2. Different orders based on auth state ← Chosen

**Decision:** Visitor sees About, Reviews, Feed, Sessions, Teachers. Signed-in user sees Feed, About, Sessions, Teachers, Reviews. Feed first for signed-in (community focus), About first for visitors (discovery focus).

**Consequences:** `buildCourseExploreTabs` now takes a `signedIn` boolean parameter.

# Conv Decisions - 2026-08-23

## 1. Strip ordinals from `## 🎯 Now`; mark co-equal runs with a band divider
**Type:** Implementation
**Topics:** cc-workflow, task-board

**Trigger:** User observed the repeated `2.`s in the execution order and questioned why numbers exist when top-down position already is the order.

**Options Considered:**
1. Strip the numbers entirely — rely on top-down position; mark co-equal runs with a `◆ **co-equal**` divider ← Chosen
2. Keep numbers but make ties explicit and self-documenting (`2a/2b/2c/2d`)

**Decision:** Option A — `## 🎯 Now` lines are now bulleted `- [CODE]` with no ordinals; position is the order; a run of co-equal tasks is grouped under a `◆ **co-equal** — order among them not significant` divider line.

**Rationale:** Ordinals are redundant with position and decay under frequent reordering (the file already had four duplicate `2.`s and a skipped `40`). The `[CODE]` anchor is the real stable key. A band divider expresses ties — the one thing pure position can't.

**Consequences:** Board migrated (48 Now lines); header note, `.claude/skills/r-update-tasks/SKILL.md` format line, and `current-tasks-check.sh` docstring updated to document the convention.

## 2. Make the checker tolerant of both TOC-line forms rather than a flag-day switch
**Type:** Implementation
**Topics:** cc-workflow, task-board

**Trigger:** `current-tasks-check.sh` required a numeric prefix on Now-lines; the two test fixtures use numbered lines, so the strip in Decision 1 would have orphaned every entry.

**Options Considered:**
1. Switch the parser to `- [` only and rewrite both test fixtures (+ the ADD/PARK/DANGLING awks that match `^N\.`)
2. Make the Now regex accept both `- [` and legacy `N. [` ← Chosen

**Decision:** Tolerant regex `(/^- \[/ || /^[0-9]+\. \[/)`.

**Rationale:** Avoids a flag-day and the churn/brittleness of rewriting fixtures; keeps any not-yet-migrated or cross-machine board valid. Style enforcement isn't the checker's job — TOC↔body consistency is.

**Consequences:** Real board migrated to bullets; both test suites stayed green unchanged (`current-tasks-check.test.sh` 7/7, `task-board-lifecycle.test.sh` 15/15).

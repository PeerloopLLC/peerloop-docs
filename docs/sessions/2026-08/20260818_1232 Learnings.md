# Conv Learnings - 2026-08-18

## 1. Tab Labels Have Two Sources
**Topics:** astro, course-page

**Context:** Renaming tabs (Modules→Sessions, etc.) — first update didn't take effect.

**Learning:** Tab labels in the course page come from TWO places: `_course-tabs.ts` (`buildCourseExploreTabs` for the tab bar) and `TAB_LABELS` in `[...tab].astro` (for page titles). Must update both.

---

## 2. Tailwind `!` Prefix for Component Override
**Topics:** tailwind, components

**Context:** Needed to override `EntityPill`'s default styles for the Meet the Creator embed.

**Learning:** Tailwind's `!` prefix (e.g. `!bg-white !px-12`) forces `!important`, allowing a parent to override a component's inline classes via `className` prop without modifying the component itself.

---

## 3. panelSpan Prop Pattern for Layout Restructuring
**Topics:** layout, astro, slots

**Context:** Client wanted the right panel to span the full page height, not just below the tab bar.

**Learning:** Added a `panelSpan: 'content' | 'full'` prop to `AppLayout` that conditionally restructures the DOM — when 'full', the entity-header/tab-bar/sub-nav/content are wrapped in a left column with the panel beside them as a sibling. This pattern allows existing pages to keep `'content'` (default) behavior unchanged.
